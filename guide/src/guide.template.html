Install and user guide

Bug Report for Google Chrome

Bug Report is a small add-on for Google Chrome. When something on a website goes wrong, or you wish it worked differently, you click one button. It takes a picture of the whole page, asks you two short questions, and saves your answers and the picture to a folder on your own PC. When you are ready, you zip that folder and send it to us.

You needA Windows PC
BrowserGoogle Chrome
The fileBugReport-extension-1.2.2.zip
TimeAbout 5 minutes

Use Google Chrome only

Please install and use Bug Report in Google Chrome. Other browsers, such as Brave or Microsoft Edge, look similar but won't save your reports correctly. If you don't have Chrome yet, download it free from google.com/chrome and install it first.

1Create your reports folder

Do this first. Your reports need a folder of their own, and Chrome is fussy about where that folder lives.

  1. Go to your Desktop, or another place you will remember.
  2. Right-click an empty space and choose New, then Folder.
  3. Name the new folder exactly BUG_REPORTS and press Enter.

Why a new folder? Chrome refuses to save into your Desktop, Documents or Downloads folders themselves. A folder inside one of them is fine. That is why BUG_REPORTS must be its own folder.

You should see a new folder called BUG_REPORTS on your Desktop. Leave it empty. Bug Report fills it for you.

2Unzip the extension

You received a file called BugReport-extension-1.2.2.zip. Chrome can't use the zip directly, so you need to unzip (extract) it first.

Unzip it somewhere permanent

Chrome runs Bug Report straight from the folder you unzip into. Put it somewhere it can stay, such as your Documents folder. Don't leave it in a temporary place, and don't delete or move that folder later. If you do, the extension stops working.

2aRight-click the zip file and choose Extract All...

2bChoose where to put it, then click Extract

Click Browse... and pick your Documents folder, or type a path such as C:\Users\YourName\Documents\BugReport. The path in the picture below was only used for this guide, and yours will be different.

2cCheck the folder

You should see nine files, including one called manifest.json.

3Open Chrome's extensions page

Open Google Chrome. Click in the address bar at the top, type chrome://extensions and press Enter.

Another way: click the ⋮ menu (three dots, top right of Chrome), then Extensions, then Manage Extensions.

You should see a page titled Extensions.

4Turn on Developer mode

Bug Report is installed from a file rather than from the Chrome Web Store. Chrome only allows that when Developer mode is on. It is a normal Chrome setting and is safe to use.

4aClick the Developer mode switch at the top right

4bCheck it is on

The switch turns blue, and the buttons Load unpacked, Pack extension and Update appear.

Leave Developer mode switched on. If you turn it off later, Chrome turns Bug Report off too.

5Load the extension

5aClick Load unpacked

It is the button highlighted in the picture in Step 4b. A window opens called "Select the extension directory."

5bPick the folder you unzipped in Step 2

Go to the folder you unzipped, the one that has manifest.json inside it. Click it once so it is highlighted, then click Select Folder.

5cCheck it has loaded

You should see a card called Bug Report 1.2.2 with its blue switch turned on.

6Pin the button to your toolbar

Pinning puts the Bug Report button next to the address bar, so it is always one click away.

6aClick the puzzle piece, then the pin next to Bug Report

The puzzle piece icon is at the top right of Chrome, next to the address bar. In the list that opens, click the pin icon on the Bug Report row.

6bCheck the button is there

You should see a small grey B button at the top right of Chrome. That's it, Bug Report is installed.

7Your first report

The first report takes a few extra clicks, because you tell Chrome which folder to save into. After that, it is much quicker.

7aGo to the page with the problem and click the B button

7bWait a moment while it takes the picture

A bar appears at the top of the page saying 'Bug Report' started debugging this browser, with a Cancel button. This is normal. Chrome shows it every time Bug Report takes a full-page picture. It closes by itself after a few seconds. Please don't click Cancel.

7cA new tab opens with your report form

You should see Report a bug or feature, the page's name and address, and a small picture of the page.

7dFill in the form

Choose Bug or Feature at Type. Answer both questions and type your name. Then click Save report. See section 11 for tips on good answers.

7eChrome asks where to save

A window opens called "Select where this site can save changes". It may open in your Documents folder, as here.

7fGo to your BUG_REPORTS folder

Find the BUG_REPORTS folder you made in Step 1. If you made it on your Desktop, click Desktop in the list on the left of the window.

If you skipped Step 1, you can make the folder here instead. Go to your Desktop, click New folder, type BUG_REPORTS and press Enter.

7gClick BUG_REPORTS once, then click Select Folder

Check that the Folder: box at the bottom says BUG_REPORTS before you click Select Folder.

If you see "Can't open this folder"

The message says "Bug Report can't open this folder because it contains system files". It means you picked Desktop, Documents or Downloads itself, rather than the folder inside it. Click Choose a different folder and pick BUG_REPORTS.

7hClick Allow

Chrome asks "Allow this site to edit files?" and says "Bug Report will be able to edit files in BUG_REPORTS". Click Allow. This only lets Bug Report write into that one folder.

7iYour report is saved

You should see the green message Saved to BUG_REPORTS/reports.csv. Below it is a line starting "Screenshot: screenshots/" with the picture's name, ending "Zip the BUG_REPORTS folder and send it when you are ready." Click Close tab to go back to what you were doing.

8Your second report

Your next report has one more question from Chrome. Answer it the right way and you won't be asked again.

8aMake a report as before and click Save report

Click the B button on the page, fill in the form and click Save report. This time the form shows Saving to: BUG_REPORTS, and your name is already filled in.

8bClick Allow on every visit

A box appears at the top left saying "Bug Report wants to" and "View and edit files from the last time you visited this site:", with BUG_REPORTS below. There are three buttons.

Choose "Allow on every visit", not "Allow this time"

Allow on every visit means Chrome remembers your choice, and you won't see this box again. If you pick Allow this time, Chrome will ask you again on every single report.

8cSaved again

From now on there are no more prompts. You click the B button, answer the questions and click Save report.

9Where your reports are kept

Open your BUG_REPORTS folder in File Explorer. All your reports are in it.

BUG_REPORTS reports.csv one row per report, opens in Excel screenshots 2026-10-06 2054 Bug - Bug tracking system - Wikipedia.png 2026-10-06 2055 Feature - Example Domain.png

9aThe folder holds one list and one folder of pictures

9bThe screenshots folder holds the pictures

Each picture is named with the date, time, type and page title, so they are easy to tell apart.

9creports.csv has one row per report

Double-click reports.csv to open it in Excel. Each row is one report, with your answers, the page address, your name and the name of its screenshot.

10Sending your reports

When you are ready to send your reports, zip the whole folder.

  1. Right-click the BUG_REPORTS folder.
  2. Choose Send to, then Compressed (zipped) folder. On Windows 11 you may need to click Show more options first. Or choose Compress to ZIP file if you see it.
  3. A new file called BUG_REPORTS.zip appears next to the folder.
  4. Email or upload that zip file, as you have been asked to.

Keep collecting reports in the same BUG_REPORTS folder afterwards. New reports are added to the list, and nothing already in it is changed.

11Bug or Feature, and writing good answers

Pick the type that fits, and the questions change to match.

TypeUse it whenQuestion 1Question 2
BugSomething is broken or doesn't work as it should.What were you trying to do?What went wrong?
FeatureIt works, but you wish it did something more or different.What couldn't you do?What would you like different?

Tips for good answers

  • Be specific. "The Save button on the Contact page does nothing" helps far more than "saving is broken".
  • Give the steps. Say what you clicked, in order, so someone else can make the same thing happen.
  • Say what you expected. Then say what happened instead. Copy any error message word for word.
  • One issue per report. If you find three problems, make three reports. Each one gets its own picture.
  • Report from the right page. Click the B button while the problem is on screen, so the picture shows it.

12Handy extras

Keyboard shortcut

Instead of clicking the B button, you can press Alt + Shift + B on the page you want to report.

Your name

You only type your name once. Bug Report remembers it after your first report and fills it in for you next time.

Changing the folder

To save into a different folder, click Change folder next to "Saving to:" on the report form (you can see it in Step 8a). Pick the new folder in the same way as before.

You can also change it in the extension's settings page. Go to chrome://extensions, click Details on the Bug Report card, scroll down and click Extension options.

The settings page shows where reports are saved. It has a Choose folder button to pick a folder, a Forget folder button to clear it, and a box for your name with a Save button.

13Troubleshooting and questions

Chrome asks for permission every time I save a report.

You probably chose "Allow this time". Next time the box appears, choose Allow on every visit. See section 8. After a full restart of Chrome it may ask once more. Choose Allow on every visit again.

It says "Can't open this folder".

You picked Desktop, Documents or Downloads itself. Click Choose a different folder and pick the BUG_REPORTS folder inside it. See section 7.

I clicked "Don't allow" by mistake.

Nothing was saved, and your answers are still on the form. Click Save report again and choose Allow this time. The form may also show Try again and Choose another folder buttons. Either one works. You can also use Change folder to pick the folder again.

I closed the folder window without choosing a folder.

Nothing was saved yet. Click Save report again and the window opens again.

It says "No screenshot could be taken".

Chrome doesn't let any extension take pictures of its own pages, such as chrome:// pages or the Chrome Web Store. This is expected. The report still saves, just without a picture.

A bar says "'Bug Report' started debugging this browser".

That's normal. Chrome shows it whenever Bug Report takes a full-page picture. It closes by itself after a few seconds. Please don't click Cancel while it is showing.

The picture of a very long page is cut off.

Very long pages are cut off at about 16,000 pixels tall. The form tells you when this happens. If the problem is further down, scroll to it and mention where it is in your answer.

The B button has disappeared, or Bug Report is turned off.

Go to chrome://extensions and check two things. First, Developer mode must still be on (Step 4). Second, the folder you unzipped in Step 2 must still be where it was. If it was moved or deleted, unzip the file again and repeat Step 5. If Bug Report is listed but switched off, turn its blue switch back on. If it is on but not in the toolbar, pin it again (Step 6).

Can I use Brave, Microsoft Edge or another browser?

Please use Google Chrome. Other browsers handle the save folder differently, and your reports may not save correctly. Get Chrome free from google.com/chrome.

Is anything sent over the internet? What about my privacy?

No. Bug Report doesn't send anything anywhere. Your reports and pictures stay on your PC, in your BUG_REPORTS folder, until you zip the folder and send it yourself. The picture only shows the page you were on when you clicked the button, so check it doesn't show anything private before you send it.

Chrome warns that Bug Report can "read and change all your data on all websites".

Chrome shows this because Bug Report needs permission to take a full-page picture of whatever page you are on. It only does this when you click the B button or press the shortcut, and only on that tab.
