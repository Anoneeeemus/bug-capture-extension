Bug Report settings

Where reports are saved

Choose a folder and every report is saved straight into it, with no prompts: one row per report in reports.csv and the pictures in screenshots. To send your reports, zip that folder and send the zip.

Create and pick a folder called BUG_REPORTS, for example on your Desktop. Chrome won't allow Desktop, Documents or Downloads themselves.

If no folder is set yet, the first report you save will ask you to choose one.
